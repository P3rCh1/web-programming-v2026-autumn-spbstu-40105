# Лабораторная работа 5

## Задание

Вариант 11. Создать интерактивную шахматную игру с возможностью игры против
игрока. Проект включает шахматную доску с фигурами, реализацию основных правил и
визуальную обратную связь при ходе.

Требования:

- отображение доски с чередующимися светлыми и тёмными клетками;
- перемещение фигур по правилам шахмат;
- определение конца игры (шах и мат);
- подсветка доступных ходов при выборе фигуры;
- поочерёдные ходы игроков;
- запрет ходов, оставляющих своего короля под шахом;
- автоматическое определение возможных ходов для каждой фигуры.

## Реализация

Приложение собрано на React + Vite и разделено на два модуля:

- `src/rules.js` — чистая шахматная логика без React: генерация псевдолегальных
  ходов каждой фигуры (`getMoves`), применение хода к копии доски (`applyMove`),
  проверка атаки клетки (`isAttacked`), шах (`isInCheck`), фильтрация легальных
  ходов (`legalMoves`), поиск любых ходов игрока для детекта мата и пата
  (`hasAnyLegalMoves`). Поддержаны взятие на проходе и превращение пешки с
  выбором фигуры (ферзь, ладья, слон, конь);
- `src/main.jsx` — React-компонент `Board`: состояние доски, текущий игрок,
  выбранная фигура и метка взятия на проходе. Клик по своей фигуре подсвечивает
  легальные ходы (`data-testid="available-move"`), клик по подсвеченной клетке
  выполняет ход. Статус партии (шах, мат, пат, чей ход) вычисляется при каждом
  рендере и выводится над доской.

Фигуры отрисованы Unicode-символами, клетки чередуются через `(r + c) % 2`.
Публичный DOM-контракт: `chess-board`, `chess-cell` (64), `chess-piece`,
`movable-piece`, `available-move`, `game-status`.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной и откройте
адрес из вывода Vite в браузере.
